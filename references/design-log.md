# Design log (read after delivery)

## Purpose
Avoid repeating the same subject, medium, and interaction combination
across sessions when a writable, persistent location is reachable this
session (for example, a saved-output or project folder Cowork keeps
between sessions).

## Before finalizing concepts
If a log file already exists at this skill's known log location, skim its
recent entries. If a similar subject recently got the same medium and
interaction pairing, favour a different one among the three solid concepts
or lean harder into the wild card.

## After delivery
Append one line to the log:
```
YYYY-MM-DD | <company/subject> | <medium chosen> | <interaction(s) chosen> | <what made this one distinct>
```

## When there's no persistent location
If nothing in this session persists between runs, skip logging entirely.
Do not fabricate or assume a history that can't actually be checked.
